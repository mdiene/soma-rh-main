**Rôles concernés** : salarié (demande), manager (étape 1), RH (étape 2). **Exemple** : une salariée fictive.

## Types disponibles
Congé annuel payé, **Congé maladie**, **Congé de maternité**, **Permission exceptionnelle**, **Absence non payée**. Le circuit est celui décrit dans [Demander et faire approuver un congé](/guide-utilisateur/demander-un-conge) : le salarié choisit le **Type de congé** dans **Nouvelle demande**, puis le manager et la RH approuvent.

## Étapes
1. **Salarié** : menu **Mes congés → Nouvelle demande**, choisissez le type, **Du**, **Au (inclus)**, **Motif**, puis **Envoyer la demande**.

   ![Demande de congé maladie](/guide-utilisateur/captures/conge-maladie.png)

   ![Demande de permission exceptionnelle](/guide-utilisateur/captures/conge-permission-exceptionnelle.png)

   ![Demande d'absence non payée](/guide-utilisateur/captures/conge-absence-non-payee.png)

   ![Demande de congé de maternité](/guide-utilisateur/captures/conge-maternite.png)
2. **Manager** : **Mon équipe et validations**, **Approuver**. **RH** : **Congés et absences**, **Approuver**.
3. **RH** : les onglets **Soldes** et **Écritures** de **Congés et absences** montrent les soldes et le détail des mouvements.

   ![Soldes de congés](/guide-utilisateur/captures/conges-soldes.png)

## Résultat attendu
Les quatre types rejoués (maladie, permission exceptionnelle, absence non payée, maternité) sont passés à l'état « Approuvée ». Le salarié reçoit une notification « Votre demande de congé est approuvée ».

## À savoir
Pour ces types, l'application accepte l'approbation **sans dotation** préalable : le solde du salarié devient alors négatif (par exemple « Congé maladie : -2 j » dans **Mon profil et mes demandes**). Ce comportement est signalé au propriétaire (fiche RPR-18) ; l'incidence sur la paie de chaque type n'est pas décrite ici.
