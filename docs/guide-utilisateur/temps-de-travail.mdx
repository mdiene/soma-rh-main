**Rôles concernés** : RH et paie. **Exemple** : le 12/11/2026, 202 salariés fictifs.

## Saisir les présences du jour
1. Menu **Présences**. Choisissez la **Date** (la page s'ouvre sur le jour courant).
2. Cliquez sur **Tout présent** (ou **Tout absent**), puis corrigez les lignes qui diffèrent : case **Présent**, **Heures travaillées**, **Absence (h)**, **Maladie (h)**, **Heures sup.**, **Taux HS**, **Commentaire**.

   ![Présences : saisie du jour](/guide-utilisateur/captures/presences-saisie.png)
3. Pour des heures supplémentaires, saisissez-les dans **Heures sup.** (exemple : 10 h travaillées et 2 h sup. pour une salariée). Le champ est libre : il n'est pas calculé à partir des heures travaillées.

   ![Heures supplémentaires saisies](/guide-utilisateur/captures/presences-heures-supplementaires.png)
4. Cliquez sur **Enregistrer** (le bouton affiche le nombre de modifications, par exemple « Enregistrer (202) »). Message : « 202 ligne(s) enregistrée(s) pour le 12/11/2026. »

   ![Présences enregistrées](/guide-utilisateur/captures/presences-enregistrees.png)

## Reporter dans les variables de paie
Le bouton **Reporter dans les variables de paie** cumule les heures d'absence, de maladie et les heures supplémentaires du mois dans les **Variables du mois**.

![Report vers les variables de paie](/guide-utilisateur/captures/presences-reportees-variables.png)

## Planning métier
Menu **Planning métier** : le bloc **Conformité de la semaine** signale les écarts de planning. Le bouton **Reporter Novembre 2026** envoie les postes de nuit vers les variables. Message relevé : « Report de Novembre 2026 : 0 présence(s) créée(s), 0 saisie(s) d'heures de nuit. »

![Planning métier, conformité de la semaine](/guide-utilisateur/captures/planning-conformite-semaine.png)

## Variables du mois
Menu **Variables du mois** (paie) : choisissez le **Mois de paie**, saisissez les variables par salarié, puis **Enregistrer**. Le bouton **Reprendre** copie les variables du mois précédent. **Enregistrer** reste inactif tant que rien n'est modifié.

![Variables du mois](/guide-utilisateur/captures/variables-du-mois.png)

## Régularisations et éléments récurrents
Menu **Prêts et régularisations** : les onglets **Régularisations** et **Éléments récurrents** s'ouvrent comme l'onglet Prêts. La saisie de ces deux onglets n'a pas été rejouée.

![Régularisations](/guide-utilisateur/captures/ajustements-regularisations.png)

## Règle de gestion
Taux et majorations des heures supplémentaires : par catégorie, paramétrés en base, statut ◐ à confirmer (voir le [Glossaire](/guide-utilisateur/glossaire)).
