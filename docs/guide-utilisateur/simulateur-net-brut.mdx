---
title: "Simuler un bulletin (net / brut)"
description: "Tester une rémunération sans rien enregistrer."
---

**Rôles concernés** : paie et RH. **Exemple** : une salariée fictive, novembre 2026.

## Étapes
1. Menu **Simulateur net / brut**. Choisissez le **Salarié** et le **Mois**. Le champ **Sursalaire** reste vide pour garder la valeur actuelle.
2. Cliquez sur **Simuler le bulletin**.

   ![Résultat de la simulation](/guide-utilisateur/captures/simulateur-net-brut.png)
3. Lisez le **Brut**, les **Retenues salariales**, le **Net à payer** et le **Coût employeur**, le détail de l'impôt sur le revenu, puis les rubriques du bulletin.
4. Pour viser un net, saisissez le **Net à payer souhaité (F CFA)** puis **Trouver le sursalaire**.

## Règle de gestion
La simulation utilise le même moteur que la paie et n'enregistre rien.
