# Ordre ROAD-02 — MFA admin et paie (GAP-007, SEC-01)

- **Date** : 2026-11-14 · **Émetteur** : soma-controle · **Agents** : `soma-base` (SQL) puis `soma-codage` (interface et passerelle) · **Sessions conseillées** : `soma-base-road02`, `soma-codage-road02`
- **Branche** : `feat/road-02-mfa` · **Phase** : 1 · **Dépend de** : ROAD-06 (garde-fou migrations) ; file `soma-base` : après ROAD-06, avant ROAD-03

## Objectif
Rendre impossible toute connexion admin ou paie sans second facteur, en ligne (Supabase Auth MFA TOTP, niveau `aal2`) et en local (TOTP dans la passerelle `api/server.mjs`, derrière l'option `totpEnabled` existante, aujourd'hui jamais lue).

## Découpage
1. **soma-base** : une migration `db/migrations/AAAAMMJJHHMMSS_mfa_aal2.sql` : fonction `require_aal2()` (ou extension de `has_role`) exigeant `aal2` pour les rôles admin et paie ; appelée par les RPC sensibles. Rollback dans `db/rollback/`, test dans `tests/sql/mfa_aal2.sql`. Fonction finie par `revoke … from public, anon` puis `grant … to authenticated`.
2. **soma-codage** (après GO sur le SQL) : écrans d'enrôlement et de saisie du code (en ligne via Supabase Auth ; en local via la passerelle), parcours de récupération, messages en français, accessibilité WCAG AA.

## Fichiers concernés
`db/migrations/`, `db/rollback/`, `tests/sql/`, `api/server.mjs`, `web/src/` (auth, pages de connexion), `web/src/lib/database.types.ts` (régénéré), `web/e2e/` (cas MFA sans casser `menu.spec.ts`, `a11y.spec.ts`).

## Critères d'acceptation
- Connexion admin et paie impossible sans second facteur, **en ligne et en local** (preuve : test).
- Rôles rh, manager, salarié : MFA facultatif, aucune régression de connexion.
- Les limites existantes (120 connexions / 15 min, verrouillage progressif RPR-03) restent intactes.
- Aucun secret TOTP dans Git ; les graines sont stockées chiffrées ou gérées par Supabase.

## Contrôles à lancer (depuis `web/` sauf mention)
`npm run check` · `npm run build` · `node --test ../tests/unit/*.test.mjs` · `scripts/test-sql.ps1` · `npx playwright test e2e/menu.spec.ts e2e/a11y.spec.ts` (un fichier à la fois si mémoire) · revue `ecc:security-reviewer` + `ecc:database-reviewer`.

## Interdits
Migration lancée en même temps qu'un autre lot `soma-base` ; `verify-payroll.ps1 -Save` ; application en ligne sans accord du propriétaire ; `git push`.
